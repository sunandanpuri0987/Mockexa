## MAC SETUP COMMANDS
============================================================

### 1. Prerequisites (install once on Mac)

Homebrew (if not installed):
  /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

Python 3.11 or 3.12 (recommended):
  brew install python@3.11
  # or download from https://www.python.org/downloads/

### 2. Extract & Enter Directory

  cd /path/to/Mockexa/Backend   # wherever you extracted the ZIP

### 3. Create Virtual Environment

  python3 -m venv .venv
  source .venv/bin/activate

### 4. Install Dependencies

  pip install --upgrade pip
  pip install -r requirements.txt

  Expected installed packages include:
    fastapi, uvicorn[standard], pydantic, gemini, PyJWT[crypto],
    pytest, httpx, python-dotenv, numpy, scikit-learn

### 5. Configure Environment

  cp .env.example .env

  Open .env and fill in the following REQUIRED values:

  ┌─────────────────────────────────────────────────────────────────┐
  │ REQUIRED VALUES TO FILL IN MANUALLY                             │
  ├─────────────────────────────────────────────────────────────────┤
  │ SUPABASE_URL          Your Supabase project URL                 │
  │                       e.g. https://abcdef.supabase.co          │
  │                                                                 │
  │ SUPABASE_ANON_KEY     Your Supabase anon/public key            │
  │                       (starts with eyJ...)                      │
  │                                                                 │
  │ SUPABASE_JWT_SECRET   Your Supabase JWT secret                  │
  │                       (found in Supabase → Settings → API)      │
  │                                                                 │
  │ GEMINI_API_KEY        Your Gemini API key (optional)              │
  │                       Required only if USE_GEMINI=True            │
  │                       Get one at https://aistudio.google.com/app/apikey │
  └─────────────────────────────────────────────────────────────────┘

  RECOMMENDED transfer configuration (start with this):
    USE_GEMINI=True
    USE_SUPABASE_PERSISTENCE=False

  When ready for live Supabase persistence:
    USE_SUPABASE_PERSISTENCE=True
    USE_GEMINI=True   # (optional — enables Gemini verification for GD)

### 6. Start the Backend

  uvicorn app.main:app --host 0.0.0.0 --port 8000

  For development with auto-reload:
    uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload

### 7. Verify Health

  curl http://127.0.0.1:8000/health

  Expected response:
    {"status":"ok","environment":"development","gemini_configured":false}

### 8. Run Tests

  python3 -m pytest tests -q

  Expected: 62 passed

## API CONTRACT SUMMARY
============================================================
  GET  /health                       Health check (unauthenticated)
  POST /technical/start              Start technical interview session
  POST /technical/answer             Submit answer for evaluation
  POST /technical/finish/{id}        Finish session and get report
  POST /hr/start                     Start HR interview session
  POST /hr/answer                    Submit HR answer for evaluation
  POST /hr/finish/{id}               Finish HR session and get report
  POST /gd/start                     Start group discussion session
  POST /gd/respond                   Submit GD turn (AI generates response)
  POST /gd/finish/{id}               Finish GD session and get feedback

  All routes except /health require:
    Authorization: Bearer <supabase_jwt_token>

## TROUBLESHOOTING
============================================================
  401 Unauthorized on all routes
    → Check SUPABASE_JWT_SECRET in .env matches your Supabase project

  Cannot connect to Supabase
    → Verify SUPABASE_URL and SUPABASE_ANON_KEY are correct
    → USE_SUPABASE_PERSISTENCE=False disables Supabase writes (safe for local dev)
