## MAC SETUP COMMANDS
============================================================

### 1. Prerequisites (install once on Mac)

Homebrew (if not installed):
  /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

Python 3.11 or 3.12 (recommended):
  brew install python@3.11
  # or download from https://www.python.org/downloads/

PyTorch (CPU or MPS — choose ONE):

  # CPU only (lighter, ~700MB):
  pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cpu

  # Apple Silicon MPS (recommended for M1/M2/M3):
  pip install torch torchvision torchaudio

  NOTE: torch must be installed BEFORE running `pip install -r requirements.txt`
  if you want to use a specific PyTorch build. Otherwise requirements.txt will
  install the default CPU torch automatically.

### 2. Extract & Enter Directory

  cd /path/to/Mockexa/Backend   # wherever you extracted the ZIP

### 3. Create Virtual Environment

  python3 -m venv .venv
  source .venv/bin/activate

### 4. Install Dependencies

  pip install --upgrade pip
  pip install -r requirements.txt

  Expected installed packages include:
    fastapi, uvicorn[standard], pydantic, groq, PyJWT[crypto],
    pytest, httpx, python-dotenv, numpy, torch, transformers,
    peft, accelerate, scikit-learn

### 5. Configure Environment

  cp .env.example .env

  Open .env and fill in the following REQUIRED values:

  ┌─────────────────────────────────────────────────────────────────┐
  │ REQUIRED VALUES TO FILL IN MANUALLY                             │
  ├─────────────────────────────────────────────────────────────────┤
  │ SUPABASE_URL          Your Supabase project URL                 │
  │                       e.g. https://abcdef.supabase.co          │
  │                                                                 │
  │ SUPABASE_ANON_KEY     Your Supabase anon/public key            │
  │                       (starts with eyJ...)                      │
  │                                                                 │
  │ SUPABASE_JWT_SECRET   Your Supabase JWT secret                  │
  │                       (found in Supabase → Settings → API)      │
  │                                                                 │
  │ GROQ_API_KEY          Your Groq API key (optional)              │
  │                       Required only if USE_GROQ=True            │
  │                       Get one at https://console.groq.com       │
  └─────────────────────────────────────────────────────────────────┘

  RECOMMENDED transfer configuration (start with this):
    USE_GROQ=False
    USE_SUPABASE_PERSISTENCE=False

  When ready for live Supabase persistence:
    USE_SUPABASE_PERSISTENCE=True
    USE_GROQ=True   # (optional — enables Groq verification for GD)

### 6. Start the Backend

  uvicorn app.main:app --host 0.0.0.0 --port 8000

  For development with auto-reload:
    uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload

### 7. Verify Health

  curl http://127.0.0.1:8000/health

  Expected response:
    {"status":"ok","environment":"development","groq_configured":false}

### 8. Run Tests

  python3 -m pytest tests -q

  Expected: 62 passed

## TROUBLESHOOTING
============================================================
  ImportError: No module named 'torch'
    → Run: pip install torch  (or see step 1 for platform-specific install)

  ImportError: No module named 'peft'
    → Run: pip install peft accelerate transformers

  401 Unauthorized on all routes
    → Check SUPABASE_JWT_SECRET in .env matches your Supabase project

  GD session hangs on first /gd/start
    → Base model is downloading from HuggingFace — wait for download to complete

  Cannot connect to Supabase
    → Verify SUPABASE_URL and SUPABASE_ANON_KEY are correct
    → USE_SUPABASE_PERSISTENCE=False disables Supabase writes (safe for local dev)
