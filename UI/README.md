# Mockexa iOS Client

Native SwiftUI app for the Mockexa AI-driven placement preparation experience.

## Run

1. Open `Mockexa.xcodeproj` in Xcode.
2. Select an iOS Simulator (e.g. iPhone 17 Pro).
3. Build and run the `Mockexa` scheme.

Configured to connect to local Mockexa FastAPI backend (`http://127.0.0.1:8000`) with Supabase authentication support.
