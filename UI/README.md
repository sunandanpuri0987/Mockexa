# Mockexa iOS Client

Native SwiftUI app for the Mockexa AI-driven placement preparation experience.

## Run

1. Open `Mockexa.xcodeproj` in Xcode.
2. Select an iOS Simulator (e.g. iPhone 17 Pro).
3. Build and run the `Mockexa` scheme.

Configured to connect to the production Mockexa FastAPI backend (`https://mockexa-api.onrender.com`) with Supabase authentication support. Local URLs remain available through configuration overrides.
